/CLOUD/SERVICE-MODELS

Modelos de servicio Cloud

MODEL · 01

IaaS

Infrastructure as a Service

Proporciona recursos de infraestructura como máquinas virtuales, redes y almacenamiento.

MODEL · 02

PaaS

Platform as a Service

Proporciona una plataforma preparada para desarrollar y ejecutar aplicaciones sin administrar toda la infraestructura.

MODEL · 03

SaaS

Software as a Service

El usuario utiliza directamente una aplicación proporcionada como servicio a través de Internet.
