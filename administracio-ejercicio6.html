Políticas Locales
de Windows

Aplicación de políticas mediante gpedit.msc y secpol.msc en Windows 11 Pro. Se configuran restricciones de usuario y equipo, seguridad, almacenamiento USB, inicio de sesión, contraseñas y bloqueo de cuenta.

OS Windows 11 Pro TOOLS gpedit.msc + secpol.msc APPLY gpupdate /force STATUS COMPLETADA
ACTIVIDAD 1.6
ÁMBITO LOCAL POLICY
PLATAFORMA WINDOWS 11 PRO
RESULTADO ● APLICADO
00 · HERRAMIENTAS

gpedit.msc vs secpol.msc

Las dos consolas administran políticas locales, pero no tienen exactamente el mismo alcance.

gpedit.msc

Editor de directivas de grupo local. Permite configurar directivas de equipo y de usuario, incluidas las Plantillas administrativas.

secpol.msc

Directiva de seguridad local. Está centrada en opciones de seguridad, contraseñas, bloqueo de cuenta y otras políticas de seguridad.

EXAMEN: Configuración del equipo afecta al ordenador; Configuración de usuario se aplica al usuario. Una política de usuario no debe confundirse con una política de equipo.
01 · SEGURIDAD

Bloqueo automático por inactividad

secpol.msc → Directivas locales → Opciones de seguridad → Inicio de sesión interactivo: Límite de inactividad del equipo
Límite configurado para la práctica 60 segundos

Se utilizó un minuto como valor de laboratorio para facilitar la comprobación. El enunciado exige el bloqueo automático, pero no fija un tiempo concreto.

EVIDENCIA · Configuración del límite de inactividad.
02 · USUARIOS

Bloquear el acceso al Panel de control

gpedit.msc → Configuración de usuario → Plantillas administrativas → Panel de control
Prohibir el acceso al Panel de control y a Configuración de PC HABILITADA

La restricción se encuentra en Configuración de usuario. Tras aplicar la política, el acceso al Panel de control queda restringido.

EVIDENCIA · Directiva de acceso al Panel de control habilitada.
VERIFICACIÓN · Windows impide el acceso tras aplicar la política.
03 · USUARIOS

Impedir cambiar el fondo de escritorio

gpedit.msc → Configuración de usuario → Plantillas administrativas → Panel de control → Personalización
Impedir cambiar el fondo de pantalla HABILITADA

La política evita que el usuario modifique el fondo del escritorio. La evidencia muestra la directiva habilitada en el Editor de directivas de grupo local.

EVIDENCIA · Restricción de cambio del fondo habilitada.
04 · DISPOSITIVOS

Almacenamiento USB en solo lectura

gpedit.msc → Configuración del equipo → Plantillas administrativas → Sistema → Acceso de almacenamiento extraíble
Discos extraíbles: denegar acceso de escritura HABILITADA

Se deniega la escritura en discos extraíbles. Esto no equivale a denegar todo acceso: la finalidad es permitir la lectura e impedir que el usuario escriba datos en el dispositivo.

EVIDENCIA · Denegación de escritura en discos extraíbles.
CLAVE: «Denegar acceso de escritura» ≠ «Denegar todo acceso». La primera opción es la adecuada para dejar el almacenamiento en modo de solo lectura.
05 · INICIO DE SESIÓN

Mensaje corporativo

secpol.msc → Directivas locales → Opciones de seguridad → Inicio de sesión interactivo
Texto del mensaje CONFIGURADO
Texto solicitado: “Va a iniciar sesión en un equipo de la empresa X. Bienvenido” . Para facilitar su visualización durante la comprobación se configuró además el título “Aviso de seguridad” .
EVIDENCIA · Configuración del texto del mensaje de inicio de sesión.
VERIFICACIÓN · Mensaje mostrado al iniciar sesión.
06 · CONTRASEÑAS

Política de contraseñas

secpol.msc → Directivas de cuenta → Directiva de contraseñas
Longitud mínima de la contraseña 10 caracteres
Requisitos de complejidad HABILITADOS
Vigencia máxima 90 días
EVIDENCIA · Valores de la política de contraseñas.
MEMORIA: longitud = número mínimo de caracteres; complejidad = requisitos de composición; vigencia máxima = tiempo máximo antes de exigir un cambio.
07 · BLOQUEO DE CUENTA

Protección ante intentos incorrectos

secpol.msc → Directivas de cuenta → Directiva de bloqueo de cuenta
Umbral de bloqueo 3 intentos
Duración del bloqueo 5 minutos
Restablecer contador después de 5 minutos

El enunciado fija los dos valores de 5 minutos, pero no indica cuántos intentos incorrectos deben provocar el bloqueo. Para el laboratorio se eligió de forma explícita un umbral de 3 intentos.

EVIDENCIA · Política de bloqueo de cuenta configurada.
08 · APLICACIÓN

Forzar actualización de las políticas

Una vez configuradas las directivas, se fuerza su actualización desde una consola con privilegios administrativos.

C:\> gpupdate /force
EVIDENCIA · Actualización forzada de directivas de equipo y usuario.
Algunas políticas pueden requerir cerrar sesión o reiniciar Windows para que el efecto sea visible. El mensaje de inicio de sesión se comprobó correctamente después del reinicio.

10 · EXAM MODE

Lo que hay que recordar

1. gpedit.msc = Editor de directivas de grupo local.

2. secpol.msc = Directiva de seguridad local.

3. Las restricciones de Panel de control y fondo usadas aquí están en Configuración de usuario.

4. La restricción USB está en Configuración del equipo.

5. Contraseñas y bloqueo de cuenta están en Directivas de cuenta.

6. gpupdate /force fuerza la actualización de las directivas.

7. Habilitar una directiva no siempre implica efecto visual inmediato: algunas requieren cerrar sesión o reiniciar.
