UNIDAD 2 · ACTIVIDAD 3

Diseño y alcance

Se implementa por PowerShell el diseño de Maderas Nexo: 30 empleados, seis departamentos y 21 puestos. Se conserva el dominio asix.test y el cliente real CLI-W11-01. Los otros 20 equipos son cuentas precreadas, no máquinas virtuales adicionales.

Tras guardar las pruebas del ejercicio gráfico, se retiró su OU de prueba y se empezó de nuevo. Esa eliminación no es parte del script de ampliación y no se debe repetir sobre la empresa ya creada.

Los ejemplos se ejecutan una sola vez en Windows PowerShell de 64 bits de SRV-DC01. Los comandos aparecen sin caracteres de continuación para facilitar el pegado. El indicador >> señala un bloque aún incompleto; antes de repetir una creación se cancela con Ctrl+C y se consulta si el objeto existe.

Grupos y pertenencias AGDLP

Se distinguen las OU contenedoras de los grupos: Globales y DominioLocal organizan los objetos; GroupScope define el ámbito real. Ambos grupos son de seguridad. La cadena de pertenencias no configura por sí sola los permisos de una carpeta.

New-ADGroup -Name 'GG_MN_ADM' -GroupScope Global -GroupCategory Security -Path 'OU=Globales,OU=Grupos,OU=MaderasNexo,DC=asix,DC=test'

Completar la empresa mediante scripts

Después de los ejemplos se utilizó Completar-MaderasNexo.ps1 junto con cuatro CSV. Se extrae todo el ZIP en el servidor y se abre INICIAR.cmd como administrador.

2Crear los grupos que faltan y añadir las pertenencias aún no existentes.8

Conserva un inventario previo e informes en Documentos\MaderasNexo-Ej3; esos informes no contienen contraseñas ni sustituyen un respaldo completo de Active Directory.

Administración posterior

Estos ejemplos son ampliaciones futuras y no se han ejecutado: añadir adm05 elevaría la plantilla a 31 usuarios, y crear Auditoría aumentaría el número de grupos. Revisar la existencia de cada objeto antes de ejecutar New-AD*.

Añadir otro usuario

# EJEMPLO DE AMPLIACIÓN: no se ejecutó en el recuento original de 30 usuarios.
$claveNueva = Read-Host 'Contraseña temporal de adm05' -AsSecureString
New-ADUser -Name 'Administracion 05' -SamAccountName 'adm05' -UserPrincipalName 'adm05@asix.test' -Path 'OU=Usuarios,OU=Administracion,OU=MaderasNexo,DC=asix,DC=test' -AccountPassword $claveNueva -Enabled $true -ChangePasswordAtLogon $true -Department 'Administración y contabilidad'
Add-ADGroupMember -Identity 'GG_MN_ADM' -Members 'adm05'

Crear otro grupo y añadir miembros

# Ejemplo: grupo de función adicional para una necesidad futura.
New-ADGroup -Name 'GG_MN_AUDITORIA' -GroupScope Global -GroupCategory Security -Path 'OU=Globales,OU=Grupos,OU=MaderasNexo,DC=asix,DC=test' -Description 'Función adicional de auditoría'
Add-ADGroupMember -Identity 'GG_MN_AUDITORIA' -Members 'adm05'
# Crear y poblar este grupo no le concede permisos sobre recursos.

Mover un usuario y cambiar de departamento

# Solo si se creó adm05 en el ejemplo anterior.
$usuario = Get-ADUser -Identity 'adm05'
Move-ADObject -Identity $usuario.DistinguishedName -TargetPath 'OU=Usuarios,OU=Comercial,OU=MaderasNexo,DC=asix,DC=test'
# Cambiar de OU NO cambia los grupos ni el atributo Department.
Set-ADUser -Identity 'adm05' -Department 'Comercial y atención al cliente'
Add-ADGroupMember -Identity 'GG_MN_COM' -Members 'adm05'
Remove-ADGroupMember -Identity 'GG_MN_ADM' -Members 'adm05' -Confirm
Get-ADUser -Identity 'adm05' -Properties Department,MemberOf | Select-Object Name,Department,DistinguishedName,MemberOf | Format-List

Mover una cuenta de OU no modifica sus pertenencias ni sus permisos. El cambio departamental requiere revisar los grupos y el acceso necesario. Aquí se conserva adm05 como identificador por tratarse de una demostración; en una empresa se define una norma de nombres estable.

Archivos utilizados

Descargar scripts y CSV. Extraer todo el paquete: el script necesita los CSV en su misma carpeta. INICIAR.cmd selecciona la consola de 64 bits; ExecutionPolicy Bypass se limita a ese proceso y no cambia la política global del servidor.

INICIAR.cmd · lanzador
@echo off
setlocal
set "PS=%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe"
if exist "%SystemRoot%\Sysnative\WindowsPowerShell\v1.0\powershell.exe" set "PS=%SystemRoot%\Sysnative\WindowsPowerShell\v1.0\powershell.exe"
"%PS%" -NoProfile -ExecutionPolicy Bypass -File "%~dp0Completar-MaderasNexo.ps1"
Completar-MaderasNexo.ps1 · código completo
param(
    [ValidateSet('Menu','Usuarios','Grupos','Equipos','Verificar')]
    [string]$Fase='Menu'
)
$ErrorActionPreference='Stop'
$base='OU=MaderasNexo,DC=asix,DC=test'
$report=$null
try {
    if(-not [Environment]::Is64BitProcess){throw 'Abrir Windows PowerShell de 64 bits.'}
    $principal=New-Object Security.Principal.WindowsPrincipal([Security.Principal.WindowsIdentity]::GetCurrent())
    if(-not $principal.IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)){throw 'Abrir como administrador del dominio.'}
    Import-Module ActiveDirectory
    $domain=Get-ADDomain
    if($domain.DNSRoot -ne 'asix.test' -or $env:COMPUTERNAME -ne 'SRV-DC01'){throw 'Ejecutar en SRV-DC01 del dominio asix.test.'}
    Get-ADOrganizationalUnit -Identity $base | Out-Null
    $users=@(Import-Csv -LiteralPath (Join-Path $PSScriptRoot 'usuarios.csv') -Encoding UTF8)
    $groups=@(Import-Csv -LiteralPath (Join-Path $PSScriptRoot 'grupos.csv') -Encoding UTF8)
    $members=@(Import-Csv -LiteralPath (Join-Path $PSScriptRoot 'pertenencias.csv') -Encoding UTF8)
    $computers=@(Import-Csv -LiteralPath (Join-Path $PSScriptRoot 'equipos.csv') -Encoding UTF8)
    if($users.Count -ne 30 -or $groups.Count -ne 18 -or $computers.Count -ne 21 -or $members.Count -ne 47){throw 'Los CSV no coinciden con el diseno aprobado.'}
    foreach($row in @($users)+@($groups)+@($computers)){
        if(-not $row.Path.EndsWith(",$base",[StringComparison]::OrdinalIgnoreCase)){throw 'Ruta CSV fuera de MaderasNexo.'}
    }
    if(($users.SamAccountName|Sort-Object -Unique).Count -ne 30){throw 'Usuarios repetidos en CSV.'}
    if(($groups.Name|Sort-Object -Unique).Count -ne 18){throw 'Grupos repetidos en CSV.'}
    if(($computers.Name|Sort-Object -Unique).Count -ne 21){throw 'Equipos repetidos en CSV.'}
    foreach($row in $users){
        $name=$row.SamAccountName
        $existing=Get-ADUser -Filter {SamAccountName -eq $name}
        if($existing -and $existing.DistinguishedName -ine "CN=$($row.Name),$($row.Path)"){throw "La cuenta $name ya existe fuera de la ubicacion esperada. No se modifica."}
    }
    foreach($row in $groups){
        $name=$row.Name
        $existing=Get-ADGroup -Filter {Name -eq $name}
        if($existing){
            if($existing.DistinguishedName -ine "CN=$name,$($row.Path)" -or [string]$existing.GroupScope -ne $row.Scope -or [string]$existing.GroupCategory -ne 'Security'){
                throw "El grupo $name existe con ubicacion o tipo diferente. Revisar antes de continuar."
            }
        }
    }
    foreach($row in $computers|Where-Object Name -NE 'CLI-W11-01'){
        $name=$row.Name
        $existing=Get-ADComputer -Filter {Name -eq $name}
        if($existing -and $existing.DistinguishedName -ine "CN=$name,$($row.Path)"){throw "El equipo $name ya existe en otra ubicacion. No se mueve automaticamente."}
    }
    if($Fase -eq 'Menu'){
        Write-Host ''
        Write-Host 'MADERAS NEXO - COMPLETAR EL EJERCICIO 3'
        Write-Host '1. Captura 7: completar OU y usuarios'
        Write-Host '2. Captura 8: completar grupos y pertenencias'
        Write-Host '3. Captura 9: completar objetos de equipo y mover el cliente real'
        Write-Host '4. Captura 10: verificacion general, sin crear ni modificar objetos'
        $choice=Read-Host 'Elegir 1, 2, 3 o 4'
        $Fase=switch($choice){'1'{'Usuarios'} '2'{'Grupos'} '3'{'Equipos'} '4'{'Verificar'} default{throw 'Opcion no valida.'}}
    }
    $stamp=Get-Date -Format 'yyyyMMdd-HHmmss'
    $report=Join-Path $env:USERPROFILE "Documents\MaderasNexo-Ej3\$stamp-$Fase"
    New-Item -ItemType Directory -Path $report -Force | Out-Null
    Get-ADObject -SearchBase $base -Filter * -Properties Description | Export-Clixml -LiteralPath (Join-Path $report 'inventario-antes.xml')
    function EnsureOU([string]$name,[string]$path){
        $found=Get-ADOrganizationalUnit -Filter {Name -eq $name} -SearchBase $path -SearchScope OneLevel
        if(-not $found){New-ADOrganizationalUnit -Name $name -Path $path -ProtectedFromAccidentalDeletion $true}
    }
    if($Fase -eq 'Usuarios'){
        $departments=@('Direccion','Administracion','Comercial','Compras','Almacen','Logistica')
        foreach($d in $departments){
            EnsureOU $d $base
            EnsureOU 'Usuarios' "OU=$d,$base"
            EnsureOU 'Equipos' "OU=$d,$base"
        }
        EnsureOU 'Grupos' $base
        EnsureOU 'Globales' "OU=Grupos,$base"
        EnsureOU 'DominioLocal' "OU=Grupos,$base"
        $newUsers=@($users|Where-Object {
            $sam=$_.SamAccountName
            -not (Get-ADUser -Filter {SamAccountName -eq $sam})
        })
        if($newUsers.Count){
            Write-Host "Se crearan $($newUsers.Count) cuentas nuevas. adm01 existente conserva su contrasena."
            Write-Host 'Solo laboratorio: se solicita una clave inicial temporal para las nuevas cuentas.'
            $password=Read-Host 'Contrasena temporal: sera obligatorio cambiarla en el primer acceso' -AsSecureString
            foreach($row in $newUsers){
                $params=@{
                    Name=$row.Name; DisplayName=$row.Name; SamAccountName=$row.SamAccountName
                    UserPrincipalName=$row.UserPrincipalName; Department=$row.Department
                    Path=$row.Path; AccountPassword=$password; Enabled=$true
                    ChangePasswordAtLogon=$true; Description='Empleado ficticio de Maderas Nexo'
                }
                New-ADUser @params
            }
            $password=$null
        }
        # Completar la ficha del usuario del ejemplo, sin alterar su clave ni pertenencias.
        foreach($row in $users){Set-ADUser -Identity $row.SamAccountName -Department $row.Department}
        $actualUsers=@(Get-ADUser -SearchBase $base -Filter * -Properties Department,UserPrincipalName)
        $actualOUs=@(Get-ADOrganizationalUnit -SearchBase $base -Filter *)
        $actualUsers|Select-Object SamAccountName,Name,Department,Enabled|Sort-Object SamAccountName|Export-Csv -LiteralPath (Join-Path $report 'usuarios.csv') -NoTypeInformation -Encoding UTF8
        $actualUsers|Group-Object Department|Sort-Object Name|Select-Object Name,Count|Format-Table -AutoSize
        Write-Host "TOTAL USUARIOS: $($actualUsers.Count) / 30"
        Write-Host "TOTAL OU: $($actualOUs.Count) / 22"
        if($actualUsers.Count -ne 30 -or $actualOUs.Count -ne 22){throw 'Los recuentos no coinciden. Revisar el informe.'}
        $disabled=@($actualUsers|Where-Object Enabled -NE $true)
        if($disabled.Count){throw 'Hay usuarios no habilitados; revisar la politica de contrasenas y el informe.'}
        Write-Host 'CAPTURA 7 COMPLETADA: OU y 30 usuarios.'
    }
    elseif($Fase -eq 'Grupos'){
        if(@(Get-ADUser -SearchBase $base -Filter *).Count -ne 30){throw 'Completar primero la fase 1: usuarios.'}
        foreach($row in $groups){
            $name=$row.Name
            if(-not (Get-ADGroup -Filter {Name -eq $name})){
                New-ADGroup -Name $name -SamAccountName $name -GroupScope $row.Scope -GroupCategory Security -Path $row.Path -Description $row.Purpose
            }
        }
        foreach($row in $members){
            $member=if($row.Member -in $users.SamAccountName){Get-ADUser -Identity $row.Member}else{Get-ADGroup -Identity $row.Member}
            $target=Get-ADGroup -Identity $row.Group -Properties member
            if($member.DistinguishedName -notin $target.member){Add-ADGroupMember -Identity $target -Members $member}
        }
        $actualGroups=@(Get-ADGroup -SearchBase $base -Filter *)
        $actualGroups|Sort-Object GroupScope,Name|Select-Object Name,GroupScope,GroupCategory|Format-Table -AutoSize
        $actualGroups|Select-Object Name,GroupScope,GroupCategory|Export-Csv -LiteralPath (Join-Path $report 'grupos.csv') -NoTypeInformation -Encoding UTF8
        foreach($example in @('GG_MN_ADM','DL_MN_ADM_M','DL_MN_ADM_L','DL_MN_COMUN_M')){
            Write-Host "MIEMBROS DE $example"
            Get-ADGroupMember -Identity $example|Select-Object Name,SamAccountName,ObjectClass|Format-Table -AutoSize
        }
        Write-Host 'CAPTURA 8: 6 globales y 12 de dominio local, con pertenencias.'
        Write-Host 'Los permisos de carpetas son diseno: no se han creado recursos SMB ni ACL.'
    }
    elseif($Fase -eq 'Equipos'){
        $client=Get-ADComputer -Identity 'CLI-W11-01' -Properties DNSHostName
        if(-not $client.Enabled){throw 'El cliente real esta deshabilitado. Revisarlo antes de continuar.'}
        $target='OU=Equipos,OU=Administracion,'+$base
        if($client.DistinguishedName -ine "CN=CLI-W11-01,$target"){
            Write-Host "Cliente real: $($client.DistinguishedName)"
            Write-Host "Destino: $target"
            $move=Read-Host 'Escribir MOVER CLIENTE para trasladar el objeto sin borrarlo ni volver a unirlo'
            if($move -cne 'MOVER CLIENTE'){throw 'Traslado cancelado. No se han creado mas objetos de equipo.'}
            Move-ADObject -Identity $client.DistinguishedName -TargetPath $target
        }
        foreach($row in $computers|Where-Object Name -NE 'CLI-W11-01'){
            $name=$row.Name
            $existing=Get-ADComputer -Filter {Name -eq $name}
            if(-not $existing){
                New-ADComputer -Name $name -SamAccountName ($name+'$') -Path $row.Path -Enabled $false -Description ('Puesto previsto de '+$row.Department+'; objeto precreado, sin VM adicional')
            }
        }
        $actualComputers=@(Get-ADComputer -SearchBase $base -Filter * -Properties Description)
        $actualComputers|Sort-Object Name|Select-Object Name,Enabled,DistinguishedName|Format-Table -AutoSize
        $actualComputers|Select-Object Name,Enabled,DistinguishedName,Description|Export-Csv -LiteralPath (Join-Path $report 'equipos.csv') -NoTypeInformation -Encoding UTF8
        Write-Host "TOTAL EQUIPOS: $($actualComputers.Count) / 21"
        Write-Host '1 cliente real y 20 objetos precreados. No se han creado otras VM.'
        if($actualComputers.Count -ne 21){throw 'Recuento de equipos no esperado.'}
        Write-Host 'CAPTURA 9 COMPLETADA.'
    }
    elseif($Fase -eq 'Verificar'){
        $actualOUs=@(Get-ADOrganizationalUnit -SearchBase $base -Filter *)
        $actualUsers=@(Get-ADUser -SearchBase $base -Filter * -Properties Department)
        $actualGroups=@(Get-ADGroup -SearchBase $base -Filter *)
        $actualComputers=@(Get-ADComputer -SearchBase $base -Filter *)
        $global=@($actualGroups|Where-Object GroupScope -EQ 'Global')
        $local=@($actualGroups|Where-Object GroupScope -EQ 'DomainLocal')
        $checks=@(
            [pscustomobject]@{Entidad='OU';Real=$actualOUs.Count;Esperado=22},
            [pscustomobject]@{Entidad='Usuarios';Real=$actualUsers.Count;Esperado=30},
            [pscustomobject]@{Entidad='Globales';Real=$global.Count;Esperado=6},
            [pscustomobject]@{Entidad='Dominio local';Real=$local.Count;Esperado=12},
            [pscustomobject]@{Entidad='Equipos';Real=$actualComputers.Count;Esperado=21}
        )
        $checks|Format-Table -AutoSize
        $checks|Export-Csv -LiteralPath (Join-Path $report 'recuentos.csv') -NoTypeInformation -Encoding UTF8
        $issues=@()
        foreach($check in $checks){if($check.Real -ne $check.Esperado){$issues+="Recuento: $($check.Entidad)"}}
        foreach($row in $users){
            $user=Get-ADUser -Identity $row.SamAccountName -Properties pwdLastSet
            if(-not $user.Enabled){$issues+="Usuario no habilitado: $($row.SamAccountName)"}
            if($user.DistinguishedName -ine "CN=$($row.Name),$($row.Path)"){$issues+="Ubicacion usuario: $($row.SamAccountName)"}
        }
        foreach($row in $groups){
            $group=Get-ADGroup -Identity $row.Name
            if([string]$group.GroupScope -ne $row.Scope -or [string]$group.GroupCategory -ne 'Security'){$issues+="Ambito/tipo: $($row.Name)"}
        }
        foreach($row in $members){
            $member=if($row.Member -in $users.SamAccountName){Get-ADUser -Identity $row.Member}else{Get-ADGroup -Identity $row.Member}
            $group=Get-ADGroup -Identity $row.Group -Properties member
            if($member.DistinguishedName -notin $group.member){$issues+="Falta $($row.Member) en $($row.Group)"}
        }
        foreach($row in $computers){
            $computer=Get-ADComputer -Identity $row.Name
            if($computer.DistinguishedName -ine "CN=$($row.Name),$($row.Path)"){$issues+="Ubicacion equipo: $($row.Name)"}
            if($row.Name -eq 'CLI-W11-01' -and -not $computer.Enabled){$issues+='Cliente real deshabilitado'}
            if($row.Name -ne 'CLI-W11-01' -and $computer.Enabled){$issues+="Objeto previsto habilitado: $($row.Name)"}
        }
        if($issues.Count){
            $issues|Out-File -LiteralPath (Join-Path $report 'incidencias.txt') -Encoding UTF8
            $issues|ForEach-Object {Write-Warning $_}
            throw 'Hay diferencias. Revisar antes de dar la practica por terminada.'
        }
        Write-Host '47 PERTENENCIAS ESPERADAS COMPROBADAS.'
        Write-Host '6 GG + 12 DL DE SEGURIDAD CORRECTOS.'
        Write-Host 'CLI-W11-01 CONSERVADO Y ORGANIZADO EN ADMINISTRACION.'
        Write-Host 'CAPTURA 10: VERIFICACION CORRECTA.'
        Write-Host 'Esta consulta no comprueba acceso a carpetas: no se han aplicado ACL.'
    }
    Write-Host ''
    Write-Host "Informes: $report"
    Write-Host 'Si se modifica una pertenencia y se prueba desde el cliente, cerrar e iniciar sesion de nuevo.'
}
catch{
    Write-Host ('ERROR: '+$_.Exception.Message) -ForegroundColor Red
    if($report){Write-Host "Informe: $report. Puede haber cambios parciales; no se elimina nada automaticamente."}
}
finally{
    $null=Read-Host 'Guardar la captura del resultado. Pulsar Enter para cerrar'
}
