SEC-ACT-008 · TÉCNICA SALAMI

Actividad 8
Técnica Salami

Análisis de una técnica basada en realizar pequeñas alteraciones repetidas que, individualmente, pueden resultar difíciles de detectar pero cuyo efecto acumulado puede llegar a ser significativo.

01 // ENUNCIADO

¿Qué debemos analizar?

La técnica Salami consiste en realizar pequeñas acciones o modificaciones que individualmente tienen un valor muy reducido, pero que repetidas sobre numerosas operaciones pueden generar un efecto importante.

02 // DEFINICIÓN

¿Qué es la técnica Salami?

🪙
0.01 + 0.01 + ...

Muchas pequeñas alteraciones

La técnica Salami consiste en realizar pequeñas modificaciones de forma repetida sobre un gran número de operaciones.

Cada modificación puede ser tan pequeña que individualmente resulte difícil de apreciar.

Sin embargo, cuando la misma acción se realiza muchas veces, la suma de todas las pequeñas cantidades puede convertirse en un valor significativo.

El nombre hace referencia a la idea de obtener pequeñas «lonchas» de muchas operaciones en lugar de realizar una única modificación de gran tamaño.

06 // DETECCIÓN

¿Por qué puede pasar desapercibida?

La característica principal de esta técnica es que cada modificación individual tiene un valor muy pequeño.


Una alteración de unos pocos céntimos puede no llamar la atención de un usuario si observa una operación de manera aislada.


El problema aparece cuando el mismo patrón se repite sobre un número muy elevado de operaciones. Por ello, para detectarlo no basta con analizar únicamente una transacción: es necesario observar patrones repetitivos y acumulaciones.

07 // SEGURIDAD DE LA INFORMACIÓN

¿Qué propiedad se compromete?

C

Confidencialidad

No es necesariamente el objetivo principal de la técnica, aunque podría verse afectada dependiendo del incidente.

I

⚠ Integridad

Es la propiedad principalmente comprometida porque se producen modificaciones no autorizadas sobre datos u operaciones.

D

Disponibilidad

El sistema puede continuar funcionando, por lo que normalmente no es la propiedad directamente atacada.

08 // PREVENCIÓN Y DETECCIÓN

¿Cómo puede detectarse?

📋

Auditoría

Registrar y revisar las operaciones realizadas sobre sistemas y datos.

📊

Análisis de patrones

Detectar pequeñas modificaciones que se repiten de forma anormal.

👥

Control de acceso

Limitar quién puede modificar información sensible y operaciones.

🧾

Trazabilidad

Poder identificar quién realizó una operación, cuándo se produjo y qué información fue modificada.

09 // MEMORY BLOCK

EXAM MODE

⚠ CONCEPTOS PARA RECORDAR
  • La técnica Salami se basa en realizar pequeñas alteraciones repetidas.
  • Cada modificación individual puede ser muy pequeña y difícil de apreciar.
  • El beneficio o perjuicio aparece por la acumulación de muchas operaciones.
  • Un ejemplo típico es modificar o desviar pequeñas cantidades económicas en numerosas transacciones.
  • En términos de CID, la propiedad más claramente afectada es la INTEGRIDAD.
  • Para detectar este tipo de comportamiento es importante analizar patrones, no solamente operaciones aisladas.
  • Auditoría, trazabilidad y control de acceso ayudan a prevenir y detectar modificaciones no autorizadas.
10 // RESPUESTA DIRECTA

Respuesta de la actividad

Técnica Salami

La técnica Salami consiste en realizar pequeñas modificaciones o sustracciones de forma repetida sobre un gran número de operaciones. Cada modificación individual tiene un valor tan reducido que puede resultar difícil de detectar, pero la suma de todas ellas puede producir un resultado considerable.

Por ejemplo, una alteración de unos pocos céntimos puede parecer insignificante en una única operación. Sin embargo, si se repite automáticamente sobre miles de operaciones, el valor acumulado puede llegar a ser elevado.

Esta técnica compromete principalmente la integridad de la información, ya que supone modificar datos u operaciones sin autorización. Para prevenirla y detectarla son importantes mecanismos como la auditoría, la trazabilidad, el control de acceso y el análisis de patrones anómalos.
