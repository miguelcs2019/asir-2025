/07/CORE-CONCEPTS

Conceptos fundamentales del sistema operativo

Las siguientes cuestiones relacionan los resultados de la práctica con el funcionamiento interno de un sistema operativo.

25
¿Por qué no debe cualquier programa acceder a toda la memoria?
Respuesta: Porque un programa podría leer o modificar datos de otros procesos o del propio sistema , causando pérdida de información, fallos y problemas graves de seguridad.
MEMORIA · AISLAMIENTO · SEGURIDAD
26
¿Hay diferencia entre programa y proceso?
Respuesta: Sí.

Un programa es el archivo con las instrucciones.

Un proceso es una instancia de ese programa que se está ejecutando y utilizando memoria, CPU y otros recursos.
★ PREGUNTA CLAVE
27
¿Por qué son necesarios los drivers?
Respuesta: Los drivers traducen las órdenes generales de Windows a las instrucciones específicas que entiende cada dispositivo de hardware.
SOFTWARE ↔ HARDWARE
28
¿Qué diferencia existe entre modo usuario y modo kernel?
Respuesta: El modo usuario tiene permisos limitados y aislados.

El modo kernel puede acceder directamente al hardware y a toda la memoria del sistema.
★ MUY IMPORTANTE
29
¿Qué ocurriría sin el controlador de red?
Respuesta: Windows no podría comunicarse correctamente con la tarjeta de red, por lo que se perdería la conectividad de red e Internet .
30
¿Por qué necesita Windows servicios en segundo plano?
Respuesta: Porque tareas como la red, las actualizaciones, la impresión o la seguridad deben mantenerse disponibles aunque el usuario no tenga una aplicación abierta.
31
¿Por qué una aplicación no necesita conocer el hardware para crear un archivo?
Respuesta: Porque la aplicación utiliza funciones de la API del sistema operativo . Windows y sus drivers se encargan de traducirlas y comunicarse con el almacenamiento físico.
32
¿Qué relación existe entre aplicación, API, kernel y hardware?
Respuesta: La aplicación solicita una operación mediante una API; la API la transmite al kernel; el kernel controla los permisos y utiliza el driver correspondiente para comunicarse con el hardware.
