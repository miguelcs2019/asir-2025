SEC-ACT-004 · MECANISMOS BÁSICOS DE SEGURIDAD

Actividad 4
Autenticación

Identificación de usuarios, prevención de accesos no autorizados y utilización de múltiples factores de autenticación para aumentar la seguridad de los sistemas.

01 // ENUNCIADO

¿Qué nos pregunta la actividad?

> ¿Podríamos decir que las técnicas de autenticación son un mecanismo de prevención en términos de seguridad informática?

Explica la respuesta.

02 // RESPUESTA

Sí. La autenticación es un mecanismo preventivo.

SÍ

Las técnicas de autenticación pueden considerarse mecanismos de prevención porque permiten comprobar la identidad de una persona antes de concederle acceso a un sistema, aplicación, servicio o recurso.

Su objetivo es evitar que una persona que no está autorizada pueda acceder utilizando una identidad que no le pertenece.

Por ejemplo, cuando introducimos un nombre de usuario y una contraseña, el sistema comprueba las credenciales antes de permitir el acceso. Si las credenciales no son válidas, el acceso es rechazado.

Por tanto, la autenticación actúa antes de que se produzca el acceso, reduciendo la posibilidad de accesos no autorizados. Por este motivo tiene una función principalmente preventiva.

04 // FACTORES DE AUTENTICACIÓN

Tres formas de demostrar quién eres

🔑
FACTOR_01

Algo que sabes

Información secreta que solamente debería conocer el usuario.

Contraseña · PIN
📱
FACTOR_02

Algo que tienes

Un objeto o dispositivo que se encuentra en posesión del usuario.

Móvil · Token · Tarjeta
👁
FACTOR_03

Algo que eres

Una característica biométrica propia de la persona.

Huella · Rostro · Iris
05 // MFA

Autenticación multifactor

2FA

MFA / 2FA

La seguridad puede aumentarse utilizando más de un factor de autenticación.

Por ejemplo, podemos utilizar una contraseña junto con un código generado en el teléfono móvil.

De esta forma, conocer únicamente la contraseña puede no ser suficiente para acceder a la cuenta.

06 // CONCEPTO IMPORTANTE

Autenticación ≠ Autorización

🔐 Autenticación

¿QUIÉN ERES?

Comprueba que el usuario es realmente quien afirma ser.

Ejemplo: iniciar sesión utilizando usuario y contraseña.

🛡 Autorización

¿QUÉ PUEDES HACER?

Determina qué recursos y operaciones puede utilizar un usuario una vez identificado.

Ejemplo: un administrador puede crear usuarios, mientras que un usuario normal no.

07 // MEMORY BLOCK

EXAM MODE

⚠ CONCEPTOS PARA RECORDAR
  • La autenticación comprueba la identidad de un usuario.
  • Se considera un mecanismo preventivo porque intenta evitar accesos no autorizados antes de que se produzcan.
  • Los factores pueden basarse en algo que sabes, algo que tienes o algo que eres.
  • Utilizar varios factores aumenta la seguridad: MFA / 2FA.
  • Autenticación responde «¿quién eres?» y autorización responde «¿qué puedes hacer?».
  • La autenticación es una medida importante, pero no garantiza por sí sola toda la seguridad de un sistema.
08 // RESPUESTA DIRECTA

Si apareciera en un examen...

La autenticación puede realizarse mediante factores como contraseñas, dispositivos o datos biométricos, y su seguridad aumenta cuando se combinan varios factores mediante MFA o 2FA.
