Opciones de pago

¿Por qué no Spot?
El requisito indica que la aplicación debe permanecer accesible y no puede ser interrumpida. Las instancias Spot están orientadas a cargas que pueden tolerar interrupciones.

/MEMORY/BLOCK

Exam Mode

MCS MEMORY BLOCK · AWS COSTS
EC2 = COMPUTACIÓN

Amazon EC2 proporciona capacidad de computación mediante instancias virtuales.

EBS = ALMACENAMIENTO EN BLOQUES

EBS proporciona volúmenes de almacenamiento utilizados por las instancias EC2.

S3 = ALMACENAMIENTO DE OBJETOS

Amazon S3 almacena objetos en buckets y no debe confundirse con un disco EBS.

VPC = RED VIRTUAL

La VPC organiza la red de los recursos AWS. En este ejercicio no se añade como grupo de coste.

DATA TRANSFER

En esta práctica se estima 1 TB mensual de tráfico de salida desde EC2 hacia Internet.

PRICING CALCULATOR

Sirve para realizar una estimación de costes de una arquitectura antes de desplegar los recursos.

⚠ TRAMPA DE EXAMEN

EC2 ≠ EBS ≠ S3.
EC2 proporciona computación.
EBS proporciona almacenamiento en bloques asociado a EC2.
S3 proporciona almacenamiento de objetos.

Tampoco confundas los 2 TB de S3 con el 1 TB de transferencia hacia Internet: son conceptos completamente diferentes.
