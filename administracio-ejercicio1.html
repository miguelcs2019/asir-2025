¿Qué es un Sistema Operativo?

Sistema Operativo · SO

Un sistema operativo es el software fundamental que administra los recursos de un ordenador o dispositivo.

Actúa como intermediario entre el hardware, las aplicaciones y el usuario.

Sin un sistema operativo, el usuario tendría que controlar directamente el procesador, la memoria, el almacenamiento y los dispositivos.

Principales funciones

⚙️

Procesos

Controla la ejecución de programas y reparte el tiempo de CPU.

🧠

Memoria

Gestiona la memoria RAM utilizada por programas y procesos.

📁

Archivos

Organiza archivos, directorios, unidades y sistemas de archivos.

🖨️

Dispositivos

Gestiona periféricos mediante controladores o drivers.

👥

Usuarios

Gestiona cuentas, grupos, permisos y sesiones.

🛡️

Seguridad

Controla autenticación, permisos y protección del sistema.

REQUISITOS MÍNIMOS

Android no se instala normalmente como un sistema operativo genérico de PC.

La compatibilidad depende del fabricante, SoC, arquitectura, memoria, almacenamiento, pantalla y certificación del dispositivo.

Google define requisitos técnicos mediante documentos de compatibilidad para fabricantes.

IMPORTANTE: No existe un único requisito del tipo «4 GB de RAM para todos los móviles Android». La compatibilidad depende del dispositivo y de su fabricante.

ChromeOS

Google · Chromebook · Cloud

ACTUALIZACIÓN Continua

PRINCIPALES CARACTERÍSTICAS

  • Sistema operativo desarrollado por Google.
  • Utilizado principalmente en Chromebooks.
  • Basado en tecnologías Linux.
  • Gran integración con servicios web y cloud.
  • Actualizaciones automáticas.
  • Orientado a sencillez, seguridad y administración.

VERSIONES

ChromeOS utiliza un modelo de actualización continua y recibe nuevas versiones de forma periódica.

Por ello, en lugar de hablar de grandes generaciones como Windows, normalmente se identifica mediante su número de versión y canal de actualización.

CHROMEOS FLEX · REQUISITOS MÍNIMOS

CPU Intel / AMD x86-64
RAM 4 GB
STORAGE 16 GB
BOOT Arranque desde USB
OJO: ChromeOS y ChromeOS Flex no son exactamente lo mismo. ChromeOS viene integrado en Chromebooks. ChromeOS Flex permite reutilizar determinados PC y Mac compatibles.
