01
PREPARACIÓN Y COPIA DE SEGURIDAD

Guardar el estado anterior

Enunciado: llevar a cabo las modificaciones del registro, comprobar el resultado, realizar previamente una copia de seguridad y restaurar el registro al finalizar. Las capturas documentan la copia de seguridad, los ajustes del registro y su restauración. El apartado de mensajes detallados incluye la configuración y una explicación de su funcionamiento.

Realizar preferiblemente en una máquina virtual. Crear una instantánea con la máquina apagada antes de comenzar. Usar el mismo usuario durante la práctica y anotar los valores originales antes de editarlos.

  1. Pulsar Win + R, ejecutar winver y guardar la versión y edición de Windows.
  2. Crear una carpeta Actividad-1.7 para las copias y pruebas.
  3. Abrir regedit y aceptar la elevación de permisos.
  4. Seleccionar Equipo → Archivo → Exportar, elegir el intervalo Todo y guardar registro-antes-act7.reg.
  5. Exportar también las ramas existentes que se vayan a editar mediante Archivo → Exportar → Rama seleccionada. Si una clave o valor no existe, anotar su ausencia para eliminar únicamente lo creado al restaurar.

02
MODIFICACIÓN 1

Desactivar el menú contextual simplificado

Documentar primero el menú que aparece al hacer clic derecho sobre un archivo. Después configurar el ajuste del menú clásico.

HKEY_CURRENT_USER\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32
  1. Abrir HKEY_CURRENT_USER\Software\Classes\CLSID.
  2. Comprobar si existe la clave {86ca1aa0-34aa-4e8b-a509-50c905bae2a2}. Si no existe, crearla mediante Nuevo → Clave.
  3. Crear dentro InprocServer32, si falta. Si ya existía, guardar su estado antes de editar.
  4. Abrir (Predeterminado), dejar los datos vacíos y pulsar Aceptar. Debe quedar una cadena vacía, no un valor sin establecer.
  5. Reiniciar Windows y hacer clic derecho sobre el mismo archivo.

Resultado esperado: apertura directa del menú clásico. Resultado observado: el menú clásico aparece directamente tras reiniciar, como se muestra en la captura 6.

La compatibilidad de este ajuste puede variar según la compilación de Windows 11. Si no produce el efecto esperado, documentar la versión y el resultado real, sin presentar el cambio como conseguido.

03
MODIFICACIÓN 2

Desactivar la pantalla de bloqueo

Pulsar Win + L antes de modificar el registro y documentar la pantalla con fondo, fecha y hora.

HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\Personalization
  1. Crear Personalization dentro de Windows únicamente si no existe.
  2. Anotar si existe NoLockScreen y guardar sus datos originales.
  3. Si falta, crear un DWORD (32 bits) llamado NoLockScreen, incluso en Windows de 64 bits.
  4. Establecer sus datos en 1.
  5. Reiniciar y pulsar Win + L para comprobar el efecto.

Resultado esperado: aparecer directamente en la pantalla de inicio de sesión, sin la pantalla previa con fecha y hora. Se mantiene la autenticación. Resultado observado: al bloquear la máquina virtual aparece directamente la pantalla de inicio de sesión.

La directiva está documentada para las ediciones Pro, Enterprise y Education, entre otras. La edición y las políticas existentes pueden condicionar el resultado.

04
MODIFICACIÓN 3

Aumentar la velocidad de los menús y submenús

HKEY_CURRENT_USER\Control Panel\Desktop
  1. Localizar MenuShowDelay y registrar sus datos originales; habitualmente son 400.
  2. Conservar el tipo Cadena (REG_SZ) y establecer los datos en 100.
  3. Reiniciar Windows.
  4. Comparar la apertura de un submenú clásico al pasar el ratón, por ejemplo clic derecho en el escritorio → Nuevo, antes y después.

Resultado esperado: menor espera para desplegar submenús clásicos. No garantiza acelerar el Inicio moderno de Windows 11. Configuración aplicada: REG_SZ con datos 100, documentada en la captura 11. Las imágenes muestran el ajuste; no constituyen una medición del tiempo de apertura.

Las capturas acreditan el valor configurado. Una grabación breve antes y después permite observar el cambio de tiempo; una imagen estática no mide la velocidad.

05
MODIFICACIÓN 4

Mostrar información detallada durante el inicio y apagado

HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System
  1. Registrar si existe VerboseStatus y sus datos originales.
  2. Crear el valor si falta, de tipo DWORD (32 bits), y asignarle 1.
  3. Si DisableStatusMessages existe y vale 1, registrar ese estado y cambiarlo a 0. Si no existe, no crearlo.
  4. Reiniciar Windows y observar los mensajes de inicio y cierre de sesión.

Resultado esperado: mensajes más específicos sobre las tareas que Windows realiza durante estas transiciones. Este apartado documenta el valor configurado; no incluye una captura del efecto durante el reinicio.

VerboseStatus permite solicitar mensajes de estado más detallados. DisableStatusMessages puede impedir que se muestren si está activado. Para comprobar el efecto se observa un reinicio completo y las transiciones de inicio o cierre de sesión. En esta actividad se aporta la configuración del registro y esta explicación, sin afirmar que se hayan observado los mensajes. La referencia de Microsoft enlazada corresponde a Windows Server antiguo.

06
RESTAURACIÓN Y COMPROBACIÓN FINAL

Recuperar los valores originales

Importar un archivo .reg combina sus entradas con las existentes: no elimina automáticamente las claves y valores nuevos. Retirar únicamente lo creado en la práctica y recuperar los datos originales de lo que ya existía.

  1. Si se creó la clave CLSID del menú clásico, eliminar esa clave específica. Si ya existía, restaurar solamente lo modificado.
  2. Eliminar NoLockScreen si se creó; si existía, devolver sus datos originales. Eliminar Personalization solo si se creó durante la práctica y ha quedado vacía.
  3. Restaurar MenuShowDelay a los datos originales anotados.
  4. Eliminar VerboseStatus si se creó, o recuperar sus datos originales. Restaurar también DisableStatusMessages si se modificó.
  5. En esta práctica se restauran manualmente los cambios descritos. La copia registro-antes-act7.reg se conserva como respaldo. Para recuperar entradas exportadas se utiliza Archivo → Importar; la importación no elimina las entradas nuevas y puede encontrar valores protegidos. No se presenta como una operación realizada en las capturas.
  6. Reiniciar y comprobar el menú contextual, la pantalla de bloqueo y el resto de los ajustes. Si es necesario recuperar toda la máquina virtual, conservar primero las pruebas fuera de ella y usar la instantánea previa.

Conclusión: la práctica documenta una copia de seguridad del registro, la activación del menú contextual clásico, la desactivación de la pantalla de bloqueo, el ajuste de MenuShowDelay y la configuración de VerboseStatus. La restauración se realizó retirando los ajustes nuevos y recuperando el valor original del retraso de los menús. Las capturas finales documentan las comprobaciones del menú y de la pantalla de bloqueo. El efecto visual de los mensajes detallados se explica, sin aportar una captura de su ejecución.
