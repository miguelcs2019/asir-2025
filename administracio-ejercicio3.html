/ACTIVITY/OBJECTIVE

Objetivo de la práctica

El objetivo de esta práctica es aprender a crear una máquina virtual en VirtualBox , asignarle los recursos necesarios, montar una imagen ISO de Ubuntu Server como medio de instalación e instalar correctamente el sistema operativo.


Al finalizar tendremos un servidor Ubuntu virtualizado, funcional y preparado para su posterior administración.

/VIRTUALIZATION/ISO

¿Qué estamos haciendo?

ISO

Imagen ISO

Una imagen ISO es un archivo que contiene una copia del contenido de un medio de instalación. VirtualBox puede montar este archivo como si fuera una unidad óptica física introducida en el ordenador.

De esta forma podemos arrancar la máquina virtual desde la ISO e instalar Ubuntu Server dentro del disco virtual.

/INSTALLATION/PROCEDURE

Proceso de instalación paso a paso

01

Crear la máquina virtual

Abrimos VirtualBox y creamos una nueva máquina virtual para Ubuntu Server.

  • RAM: mínimo 2 GB.
  • Recomendado: 4 GB si el equipo lo permite.
  • Procesador: 2 núcleos si es posible.
  • Disco virtual: mínimo 20 GB.
✔ La máquina virtual utiliza recursos del ordenador físico, pero funciona como un equipo independiente.
02

Montar la imagen ISO

Seleccionamos la imagen ISO de Ubuntu Server para utilizarla como medio de instalación.

ubuntu-server.iso

VirtualBox presentará esta ISO a la máquina virtual como una unidad de instalación.

IMPORTANTE → La ISO no es el sistema ya instalado. Es el medio desde el que instalaremos Ubuntu en el disco virtual.
03

Arrancar desde la ISO

Iniciamos la máquina virtual.

El sistema arrancará utilizando la imagen ISO montada y aparecerá el instalador de Ubuntu Server.

Install Ubuntu Server
04

Idioma y teclado

Seleccionamos el idioma deseado para la instalación.

También configuramos la distribución del teclado correspondiente.

  • Idioma: el indicado para la práctica.
  • Teclado: español si corresponde.
05

Configuración de red

Durante la instalación Ubuntu detectará la interfaz de red virtual.

En una instalación básica podemos utilizar configuración automática mediante DHCP.

DHCP → configuración automática
✔ Si la práctica no solicita una IP fija, podemos mantener la configuración automática.
06

Proxy y repositorios

Si nuestra red no utiliza un servidor proxy, dejamos este campo vacío.

El repositorio o mirror de Ubuntu puede mantenerse con la configuración propuesta por el instalador.

✔ En una instalación estándar no es necesario modificar estas opciones.
07

Particionado del disco virtual

Seleccionamos el disco virtual creado anteriormente.

Para esta práctica podemos utilizar el particionado automático.

Use entire disk
  • Seleccionar el disco virtual.
  • Utilizar particionado automático.
  • Revisar el resumen.
  • Confirmar los cambios.
IMPORTANTE → Estamos trabajando sobre el DISCO VIRTUAL de la VM, no sobre el disco físico del ordenador anfitrión.
08

Crear usuario y nombre del servidor

Configuramos la identidad del nuevo servidor.

  • Nombre del usuario.
  • Nombre del servidor o hostname.
  • Nombre de inicio de sesión.
  • Contraseña.
✔ Utilizar una contraseña segura y recordar las credenciales configuradas.
09

Instalar OpenSSH Server

Durante la instalación podemos activar:

Install OpenSSH server

OpenSSH permitirá administrar posteriormente el servidor de forma remota mediante SSH.

  • Administración remota.
  • Conexión mediante terminal.
  • No necesitamos trabajar siempre desde la consola de VirtualBox.
✔ Recomendado para un servidor que posteriormente vamos a administrar por red.
10

Paquetes adicionales

El instalador puede mostrar servicios o paquetes adicionales.

Si la práctica únicamente solicita instalar el sistema operativo, podemos mantener una instalación básica.

  • No instalar servicios que no necesitemos.
  • Los servicios pueden añadirse posteriormente.
  • Mantener inicialmente un sistema sencillo.
11

Finalizar la instalación

Esperamos a que Ubuntu complete la copia e instalación de los archivos.

Cuando aparezca la opción correspondiente, reiniciamos la máquina virtual.

Reboot Now
12

Retirar la ISO y arrancar Ubuntu

Después de completar la instalación, la máquina debe arrancar desde el disco virtual y no volver a iniciar el instalador.

  • Retirar o desmontar la ISO si fuera necesario.
  • Reiniciar la máquina virtual.
  • Esperar al arranque de Ubuntu Server.
  • Iniciar sesión con el usuario creado.
Si vuelve a aparecer el instalador después del reinicio, hay que comprobar que la ISO no esté configurada como medio de arranque prioritario.
