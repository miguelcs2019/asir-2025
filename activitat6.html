03 // VULNERABILIDAD ELEGIDA

MS17-010 · SMB

ETERNALBLUE
CRITICAL VULNERABILITY

La vulnerabilidad conocida mediante el boletín MS17-010 afectaba a determinadas versiones de Microsoft Windows y estaba relacionada con el protocolo SMB.


SMB se utiliza para funciones como compartir archivos y otros recursos a través de una red. La vulnerabilidad podía permitir ejecución remota de código mediante paquetes especialmente preparados.

05 // CASO REAL

WannaCry · 2017

🔒
WANNACRY

Un ataque real

En mayo de 2017 apareció WannaCry, un ataque de ransomware que afectó a numerosos sistemas Windows.

WannaCry utilizó EternalBlue para aprovechar la vulnerabilidad de SMB y propagarse entre sistemas vulnerables.

Una vez infectado un equipo, el ransomware podía cifrar archivos y mostrar una petición de pago para intentar recuperar el acceso a la información.

Una característica especialmente importante fue su capacidad de propagación, que permitió que el incidente alcanzara rápidamente sistemas de múltiples organizaciones.

07 // PREVENCIÓN

La importancia de actualizar

🛡️ Parche de seguridad

Microsoft había publicado una actualización de seguridad para corregir las vulnerabilidades tratadas en MS17-010.


El caso demuestra la importancia de mantener los sistemas actualizados y aplicar los parches de seguridad disponibles.


Un sistema que mantiene vulnerabilidades conocidas sin corregir puede quedar expuesto incluso cuando ya existe una actualización que soluciona el problema.

09 // RESPUESTA DIRECTA

Respuesta de la actividad

Vulnerabilidad elegida: MS17-010 / EternalBlue

Un caso real de explotación de una vulnerabilidad fue el ataque de ransomware WannaCry en mayo de 2017. El ataque afectó a sistemas Windows y utilizó EternalBlue para aprovechar vulnerabilidades relacionadas con el protocolo SMB.

WannaCry podía propagarse entre sistemas vulnerables y cifrar archivos, impidiendo que los usuarios accedieran normalmente a su información y mostrando una petición de rescate.

Como consecuencia, numerosas organizaciones de distintos países sufrieron equipos afectados, interrupciones de servicios y costes asociados a la recuperación de los sistemas.

Este caso demuestra la importancia de mantener los sistemas actualizados y aplicar los parches de seguridad para corregir vulnerabilidades conocidas.
