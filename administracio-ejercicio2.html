¿Qué es la virtualización?

Virtualización

La virtualización permite crear varios sistemas informáticos virtuales sobre una misma máquina física.

Cada máquina virtual o VM puede disponer de CPU virtual, memoria, almacenamiento, red y su propio sistema operativo.

El componente encargado de gestionar y aislar estas máquinas virtuales es el hipervisor.

Hipervisor Tipo 1 vs Tipo 2

Hipervisor Tipo 1

El hipervisor se ejecuta sobre el hardware y controla directamente los recursos utilizados por las máquinas virtuales.

Está especialmente orientado a servidores, centros de datos, alta disponibilidad y producción.

  • ⚡ Alto rendimiento
  • 🛡️ Buen aislamiento
  • 🗄️ Orientado a servidores
  • 🔄 Clustering y alta disponibilidad
  • 📈 Escalable

Proxmox VE

Proxmox Server Solutions GmbH

PLATFORM KVM + LXC

LICENCIA / COSTE

OPEN SOURCE SOPORTE OPCIONAL SERVIDOR

Proxmox VE es una plataforma de virtualización de código abierto. Puede utilizarse sin adquirir una suscripción comercial. Las suscripciones proporcionan, entre otras cosas, acceso al repositorio empresarial y diferentes niveles de soporte.

TECNOLOGÍA

  • KVM para máquinas virtuales
  • LXC para contenedores
  • Interfaz web integrada
  • Clustering
  • Alta disponibilidad
  • Migración de máquinas
  • Gestión de almacenamiento y red

✓ VENTAJAS

  • ✓ Código abierto
  • ✓ Interfaz web muy completa
  • ✓ VM + contenedores
  • ✓ Clustering integrado
  • ✓ Excelente para homelab

✕ INCONVENIENTES

  • ✕ Requiere conocimientos de redes, Linux y almacenamiento para escenarios avanzados

  • ✕ Algunas empresas dependen de ecosistemas VMware o Microsoft ya implantados

Kernel-based Virtual Machine · Linux

TECHNOLOGY LINUX KERNEL

LICENCIA / COSTE

OPEN SOURCE HYPERVISOR

  • Virtualización asistida por hardware

  • Base de numerosas plataformas cloud
  • Utilizado por Proxmox VE

✓ VENTAJAS

  • ✓ Código abierto

  • ✓ Muy flexible
  • ✓ Excelente para automatización

✕ INCONVENIENTES

  • ✕ KVM por sí solo no proporciona una plataforma gráfica completa como Proxmox

07 //

⚠ Conceptos que suelen confundirse

!

Hyper-V NO debe memorizarse como Tipo 2

Aunque se habilite desde Windows, Hyper-V utiliza una arquitectura de hipervisor Tipo 1.

!

Proxmox y KVM no son lo mismo

KVM es la tecnología de virtualización integrada en Linux. Proxmox VE es una plataforma completa que utiliza, entre otras tecnologías, KVM para ejecutar máquinas virtuales.

!

Una VM no es lo mismo que un contenedor

Una máquina virtual dispone de un sistema operativo invitado completo. Los contenedores comparten el kernel del host y tienen una arquitectura diferente.

!

Tipo 1 y Tipo 2 dependen de la arquitectura

Tipo 1: hipervisor directamente sobre el hardware.
Tipo 2: hipervisor ejecutado sobre un sistema operativo anfitrión.
