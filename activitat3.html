02 //

Simétrico vs Asimétrico

🔑

Cifrado Simétrico

UNA CLAVE

Utiliza una única clave secreta que debe conocer tanto el emisor como el receptor.

  • 🔑 Claves: 1
  • ⚡ Velocidad: MUY ALTA
  • 📦 Grandes cantidades de datos: SÍ
  • ⚠ Problema principal: intercambio seguro de la clave
  • 🧠 Ejemplos: AES · ChaCha20
🔐

Cifrado Asimétrico

DOS CLAVES

Utiliza un par de claves matemáticamente relacionadas: pública y privada.

  • 🔑 Claves: 2
  • 🔓 Pública: puede compartirse
  • 🔐 Privada: NUNCA se comparte
  • 🐢 Velocidad: más lenta
  • ✍️ Permite: firma digital
  • 🧠 Ejemplos: RSA · ECC

Funciones Hash

#️⃣ ¿Qué es un HASH?

Una función hash transforma unos datos de entrada en una huella digital de longitud determinada.

Se utiliza para comprobar la integridad de la información.

Si cambia incluso una pequeña parte del documento, su hash cambia de forma significativa.

MUY IMPORTANTE HASH ≠ CIFRADO

Un HASH NO se descifra.

¿Qué aporta una firma digital?

👤

Autenticidad

Permite verificar la identidad asociada al firmante.

🧱

Integridad

Permite detectar si el documento ha sido modificado después de firmarse.

✍️

No repudio

Contribuye a demostrar que una determinada identidad realizó la firma, según el contexto y las garantías utilizadas.

¿Por qué se combinan?

🌐

Criptografía híbrida

EJEMPLO: TLS / HTTPS

Los sistemas modernos combinan diferentes mecanismos criptográficos.

La criptografía asimétrica, los certificados digitales y los mecanismos de intercambio de claves permiten establecer una comunicación segura.

Una vez establecida la sesión, se utiliza normalmente cifrado simétrico para proteger los datos porque es mucho más rápido y eficiente.

10 //

⚠ Trampas de examen

✕

"La clave privada se envía al receptor"

FALSO. La clave privada debe permanecer bajo el control de su propietario. NUNCA se comparte.

✕

"Firmar digitalmente significa ocultar el documento"

FALSO. Firma y cifrado tienen finalidades diferentes.

La firma digital permite comprobar principalmente autenticidad e integridad.

✕

"Un hash se puede descifrar"

FALSO. Una función hash criptográfica está diseñada para ser unidireccional.

Hash y cifrado NO son lo mismo.

✕

"El certificado digital contiene la clave privada"

FALSO. El certificado contiene la clave pública junto con datos de identidad, información del emisor y su firma digital.

✕

"Cifrado simétrico significa que hay dos claves iguales"

FALSO. Se utiliza una misma clave secreta para cifrar y descifrar.

✕

"Para firmar se utiliza la clave pública"

FALSO. Para realizar una firma digital se utiliza la CLAVE PRIVADA del firmante.

La CLAVE PÚBLICA se utiliza para verificar la firma.
