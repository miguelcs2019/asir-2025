01
ACTIVIDAD 1.9

Objetivo y destino

Objetivo: automatizar las particiones, la aplicación de una imagen de Windows 11 Pro y el arranque UEFI desde WinPE. La selección de edición, la confirmación de borrado y OOBE son manuales: se automatiza el despliegue, no toda la configuración inicial.

WinPE→ Validación→ GPT→ DISM→ BCDBoot→ Windows

Se reutiliza WINPE-LAB con su disco vacío de 64 GB, y la ISO Win11_25H2_Spanish_x64_v2.iso. La VM que ya tiene Windows 11 Pro instalado se conserva.

Destino exclusivo: un único VDI VBOX de 64 GB vacío en WINPE-LAB. El proceso borra ese disco. Crear antes una instantánea con la VM apagada. No conectar discos físicos, USB ni otros VDI.

Resultado: se ha desplegado Windows 11 Pro desde la imagen oficial, se ha arrancado desde el disco virtual y se ha comprobado Windows RE habilitado. Las capturas documentan las fases del proceso; la captura 8 reúne la aplicación de la imagen, la creación del arranque y el resumen final.

02
ACTIVIDAD 1.9

Añadir los scripts a WinPE

  1. Extraer actividad9-despliegue.zip en el Windows 10 anfitrión. Incluye ASIX\desplegar.cmd y ASIX\particiones-uefi.txt.
  2. Copiar ASIX completa en C:\WinPE_amd64\media.
  3. WinPE básico puede no incluir findstr.exe. En el anfitrión Windows 10 de 64 bits, copiar C:\Windows\System32\findstr.exe dentro de C:\WinPE_amd64\media\ASIX. Conservar también los dos archivos del paquete. El script utilizará esa copia para sus comprobaciones.
  4. Conservar la ISO original y abrir el entorno elevado del ADK para generar una ISO nueva:
MakeWinPEMedia /ISO C:\WinPE_amd64 C:\WinPE_amd64\WinPE_ASIX_Act9.iso /bootex

Incidencia y solución: en el primer intento WinPE indicó que findstr no se reconocía. El script se detuvo antes del particionado. Se añadió una copia x64 de findstr.exe desde System32 del anfitrión y se regeneró la ISO. En el siguiente intento se detectó otra incidencia: DiskPart antepone un asterisco al disco seleccionado. Se corrigieron los patrones de lectura para admitirlo, manteniendo la exigencia de un único disco vacío de 64 GB. Además se reprodujo que la lectura directa de un listado Unicode con FINDSTR no contaba el disco. El script normaliza a ANSI los listados antes de analizarlos. El paquete incorpora PREPARAR-ISO.cmd para copiar los archivos y regenerar la ISO desde el anfitrión sin escribir comandos largos. El recuento también debía excluir el mensaje «Disk 0 is now the selected disk»: se restringió el filtro a las filas de estado Online, Offline o No Media. Tras corregir estas comprobaciones, el despliegue terminó correctamente. Los intentos fallidos se detuvieron antes de particionar el disco.

Preparación simplificada: extraer todo el ZIP en Windows 10, apagar WINPE-LAB y retirar su ISO de WinPE. Hacer clic derecho en PREPARAR-ISO.cmd → Ejecutar como administrador. El asistente copia los scripts, añade findstr.exe y genera de nuevo WinPE_ASIX_Act9.iso. No ejecuta el despliegue.

Los scripts quedan en el medio óptico, fuera de boot.wim. Se ejecutan manualmente desde WinPE; no se añade un borrado automático al arranque ni se depende de las carpetas compartidas de VirtualBox.

ACTIVIDAD 1.9

Preparar medios y revisar el disco

  1. Con WINPE-LAB apagada, comprobar 4 GB de RAM, 2 CPU, EFI y TPM 2.0 virtual. Mantener una configuración compatible con Windows 11; no se eluden sus requisitos.
  2. En Almacenamiento conservar solo el VDI vacío de 64 GB. Conectar WinPE_ASIX_Act9.iso y, en otra unidad óptica, Win11_25H2_Spanish_x64_v2.iso.
  3. Arrancar desde WinPE. Si se abre el instalador de Windows, apagar y elegir la otra unidad óptica en el menú de arranque.
  4. Consultar discos y volúmenes:
diskpart
list disk
list volume
exit

En la comprobación inicial aparecen el disco 0 de 64 GB completamente libre, la ISO de WinPE en D: con unos 380 MB y la ISO de Windows en E: con unos 8077 MB. Estas letras se identificaron en la práctica, no se presuponen para otros equipos. La lectura de la ISO local no requiere red.

04
ACTIVIDAD 1.9

Elegir la imagen y confirmar

En la consola interactiva de WinPE, localizar el script:

for %L in (C D E F G H I J K L M N O P Q T U V Y Z) do @if exist %L:\ASIX\desplegar.cmd echo %L:\ASIX\desplegar.cmd

Ejecutar la ruta que aparezca, por ejemplo D:\ASIX\desplegar.cmd solo si se ha identificado esa unidad.

El script detecta exactamente un install.wim o install.esd, muestra las ediciones y pide el índice de Windows 11 Pro. En la ISO utilizada, Windows 11 Pro corresponde al índice 6, con arquitectura x64 e idioma es-ES, leído desde E:\sources\install.wim. El número puede variar en otras ISO; por eso el script comprueba Professional x64 antes del borrado.

Se exige WinPE en X:, UEFI, letras S:/W:/R: libres y un único VBOX HARDDISK de 64 GB totalmente libre. La comprobación de DiskPart utiliza su salida inglesa, como en la actividad 8; si cambia el formato, se cancela. No retirar las comprobaciones para forzar la ejecución.

Revisar el resumen y hacer la captura 6 antes de confirmar. Solo si el destino es WINPE-LAB, escribir exactamente:

BORRAR WINPE-LAB DISCO 0

Otra respuesta cancela. No ejecutar particiones-uefi.txt directamente: solo el script principal contiene las comprobaciones previas.

ACTIVIDAD 1.9

Despliegue por fases

FaseOperación automáticaCaptura
GPTEFI FAT32 de 300 MB (S:), MSR de 16 MB, Windows NTFS (W:) y Recovery NTFS de 2048 MB (R: temporal).7, primera pausa
ImagenDISM aplica el índice seleccionado en W: y comprueba la integridad.8, captura conjunta
ArranqueBCDBoot prepara BCD y archivos UEFI en S:; se comprueba su existencia.8, captura conjunta
Recuperación y logsCopia winre.wim, registra la ubicación, retira la letra R: y guarda registros en la partición de Windows.8, captura conjunta

BCDBoot utiliza una partición EFI explícita: no crea entrada NVRAM y depende de la ruta de arranque de reserva, cuya existencia se comprueba. Si el firmware no la elige, revisar su menú de arranque.

Recovery necesita al menos 250 MB libres además de winre.wim. Se han reservado 2 GB para este laboratorio. La ubicación se registró durante el despliegue y el estado habilitado se comprobó después de iniciar Windows, como muestra la captura 15.

Ante un error, detenerse y conservar pantalla y logs. No reiniciar ni volver a ejecutar: el disco puede estar parcialmente desplegado y la comprobación de disco vacío bloqueará otra ejecución.

Al terminar, consultar los volúmenes para la captura 11 y apagar:

wpeutil shutdown
  1. Con la VM apagada, retirar ambas ISO de las unidades ópticas; conservar el VDI.
  2. Arrancar desde el disco y documentar OOBE.
  3. Completar manualmente idioma, teclado, cuenta y conexión según lo que solicite Windows.
  4. En el escritorio, ejecutar winver y comprobar Windows 11 Pro y su versión.

Aplicar una imagen no activa Windows: se necesita la licencia correspondiente. El resultado de DISM no acredita por sí solo el primer arranque; las capturas 12 y 13 documentan esa comprobación.

07
ACTIVIDAD 1.9

Verificación final

Abrir Administración de discos y revisar EFI, Windows y Recovery. MSR puede no verse en esa pantalla. Las letras S:/W:/R: eran temporales de WinPE; Windows normalmente arranca en C:.

En una consola como administrador del Windows desplegado:

reagentc /info

Resultado comprobado: Windows RE aparece como Enabled. Su ubicación corresponde al disco 0, partición 4, carpeta Recovery\WindowsRE. La versión mostrada del entorno de recuperación es 10.0.26100.8031, y REAGENTC confirma que la operación se ha efectuado correctamente.

Abrir C:\ASIX-Logs y revisar resumen.txt, edición, particionado, arranque y registro de DISM. Conservarlos junto a las capturas.

Cómo interpretar el registro: el resumen se generó antes del primer arranque; por eso puede indicar que la comprobación de WinRE se hace después de OOBE. La captura 15 aporta esa verificación posterior. No es necesario editar el registro del despliegue para sustituir ese aviso.

Conclusión: se ha automatizado el despliegue de Windows 11 Pro en WINPE-LAB mediante un script ejecutado desde WinPE. El proceso creó las particiones GPT, aplicó el índice 6 de la imagen oficial, preparó el arranque UEFI y registró la ubicación de WinRE. Tras retirar ambas ISO, Windows arrancó desde el VDI y se completó su configuración inicial. La comprobación final confirma Windows RE habilitado en la partición 4 y la conservación de los registros en C:\ASIX-Logs. La selección de edición, la confirmación del borrado y OOBE se realizaron manualmente.

Scripts del laboratorio

El ZIP contiene estos dos archivos en ASIX. Ejecutar solo el principal desde WinPE, después de revisar el destino. Se incluyen completos para consulta.

desplegar.cmd
@echo off
setlocal EnableExtensions EnableDelayedExpansion
title ASIX ACT 1.9 - SOLO WINPE-LAB
reg query "HKLM\SYSTEM\CurrentControlSet\Control\MiniNT" >nul 2>&1
if errorlevel 1 (
 echo ERROR: ejecutar solo desde WinPE, nunca desde Windows instalado.
 exit /b 1
)
if /i not "%SystemDrive%"=="X:" exit /b 1
rem Usar findstr.exe x64 copiado desde el Windows 10 anfitrion.
if not exist "%~dp0findstr.exe" (
 echo ERROR: falta ASIX\findstr.exe. Copiarlo desde C:\Windows\System32
 echo en el anfitrion Windows 10 de 64 bits y regenerar la ISO.
 exit /b 1
)
set "PATH=%~dp0;%PATH%"
"%~dp0findstr.exe" /? >nul 2>&1
if errorlevel 2 (
 echo ERROR: findstr.exe no se puede ejecutar. Detenerse y revisar arquitectura.
 exit /b 1
)
wpeutil UpdateBootInfo >nul 2>&1
reg query "HKLM\SYSTEM\CurrentControlSet\Control" /v PEFirmwareType 2>nul | findstr /i "0x2" >nul
if errorlevel 1 (
 echo ERROR: se requiere arranque UEFI.
 exit /b 1
)
if not exist "%~dp0particiones-uefi.txt" (
 echo ERROR: falta particiones-uefi.txt junto al script.
 exit /b 1
)
set "LOGDIR=X:\ASIX-Logs"
if not exist "!LOGDIR!" md "!LOGDIR!"
> "!LOGDIR!\resumen.txt" echo ASIX ACTIVIDAD 1.9 - INICIO
for %%L in (S W R) do if exist "%%L:\" (
 echo ERROR: letra %%L: ocupada. No se ha borrado nada.
 exit /b 1
)
set /a SOURCES=0
set "IMAGE="
for %%L in (C D E F G H I J K L M N O P Q T U V Y Z) do (
 if exist "%%L:\sources\install.wim" (
  set /a SOURCES+=1
  set "IMAGE=%%L:\sources\install.wim"
 )
 if exist "%%L:\sources\install.esd" (
  set /a SOURCES+=1
  set "IMAGE=%%L:\sources\install.esd"
 )
)
if not "!SOURCES!"=="1" (
 echo ERROR: se necesita exactamente un install.wim o install.esd.
 echo Revisar las dos ISO conectadas.
 exit /b 1
)
> "!LOGDIR!\consulta.txt" echo select disk 0
>> "!LOGDIR!\consulta.txt" echo detail disk
>> "!LOGDIR!\consulta.txt" echo list disk
>> "!LOGDIR!\consulta.txt" echo list volume
>> "!LOGDIR!\consulta.txt" echo exit
diskpart /s "!LOGDIR!\consulta.txt" > "!LOGDIR!\discos-antes.txt" 2>&1
if errorlevel 1 goto error
rem Normalizar a ANSI la salida de DiskPart antes de usar FINDSTR.
cmd /d /a /c type "!LOGDIR!\discos-antes.txt" > "!LOGDIR!\discos-ansi.txt"
if errorlevel 1 goto error
move /y "!LOGDIR!\discos-ansi.txt" "!LOGDIR!\discos-antes.txt" >nul
if errorlevel 1 goto error
type "!LOGDIR!\discos-antes.txt"
rem Validacion especifica de la salida inglesa del WinPE de la actividad 8.
set /a DISKS=0
for /f "delims=" %%L in ('findstr /r /c:"^[ *]*Disk [0-9][0-9]* *Online " /c:"^[ *]*Disk [0-9][0-9]* *Offline " /c:"^[ *]*Disk [0-9][0-9]* *No Media " "!LOGDIR!\discos-antes.txt"') do set /a DISKS+=1
if not "!DISKS!"=="1" (
 echo ERROR: no se identifica exactamente un disco. Recuento: !DISKS!
 exit /b 1
)
findstr /i /c:"VBOX HARDDISK" "!LOGDIR!\discos-antes.txt" >nul
if errorlevel 1 (
 echo ERROR: no se identifica el modelo VBOX HARDDISK.
 exit /b 1
)
findstr /r /c:"^[ *]*Disk 0 *Online *64 GB *64 GB" "!LOGDIR!\discos-antes.txt" >nul
if errorlevel 1 (
 echo ERROR: no coincide con disco 0 vacio de 64 GB.
 echo No modificar el script para saltarse esta comprobacion.
 exit /b 1
)
echo ORIGEN: !IMAGE!
dism /Get-ImageInfo /ImageFile:"!IMAGE!" /English
if errorlevel 1 goto error
echo CAPTURA 5: listado de ediciones. Identificar Windows 11 Pro.
:indice
set "INDEX="
set /p "INDEX=Indice de Windows 11 Pro: "
> "!LOGDIR!\indice.txt" echo(!INDEX!
findstr /r /x "[1-9][0-9]*" "!LOGDIR!\indice.txt" >nul
if errorlevel 1 goto indice
if not "!INDEX:~3!"=="" goto indice
dism /Get-ImageInfo /ImageFile:"!IMAGE!" /Index:!INDEX! /English > "!LOGDIR!\edicion.txt" 2>&1
if errorlevel 1 (
 cmd /d /a /c type "!LOGDIR!\edicion.txt" > "!LOGDIR!\edicion-ansi.txt"
move /y "!LOGDIR!\edicion-ansi.txt" "!LOGDIR!\edicion.txt" >nul
type "!LOGDIR!\edicion.txt"
 goto indice
)
cmd /d /a /c type "!LOGDIR!\edicion.txt" > "!LOGDIR!\edicion-ansi.txt"
move /y "!LOGDIR!\edicion-ansi.txt" "!LOGDIR!\edicion.txt" >nul
type "!LOGDIR!\edicion.txt"
findstr /r /c:"^Edition : Professional$" "!LOGDIR!\edicion.txt" >nul
if errorlevel 1 (
 echo El indice no es Professional.
 goto indice
)
findstr /r /c:"^Architecture : x64$" "!LOGDIR!\edicion.txt" >nul
if errorlevel 1 (
 echo ERROR: la imagen no es x64.
 exit /b 1
)
echo.
echo ===== CAPTURA 6: REVISION ANTES DE BORRAR =====
echo Destino: unico disco 0 VBOX HARDDISK, 64 GB, vacio.
echo Origen: !IMAGE!
echo Indice: !INDEX!, Professional x64.
echo Comprobar que la ventana es WINPE-LAB.
echo Se BORRARA TODO el disco 0. No utilizar en otra maquina.
echo Escribir exactamente: BORRAR WINPE-LAB DISCO 0
set "CONFIRM="
set /p "CONFIRM=Confirmacion: "
if not "!CONFIRM!"=="BORRAR WINPE-LAB DISCO 0" (
 echo CANCELADO. No se ha particionado.
 exit /b 2
)
>> "!LOGDIR!\resumen.txt" echo Origen: !IMAGE!
>> "!LOGDIR!\resumen.txt" echo Indice: !INDEX!, Professional x64.
>> "!LOGDIR!\resumen.txt" echo Destino: disco 0 VBOX vacio de 64 GB confirmado.
diskpart /s "%~dp0particiones-uefi.txt" > "!LOGDIR!\particiones.txt" 2>&1
if errorlevel 1 goto error
type "!LOGDIR!\particiones.txt"
for %%L in (S W R) do if not exist "%%L:\" goto error
vol S: | findstr /c:"ASIX_SYS" >nul
if errorlevel 1 goto error
vol W: | findstr /c:"ASIX_WIN" >nul
if errorlevel 1 goto error
vol R: | findstr /c:"ASIX_RE" >nul
if errorlevel 1 goto error
>> "!LOGDIR!\resumen.txt" echo GPT: EFI 300 MB, MSR 16 MB, Windows y Recovery 2048 MB.
echo CAPTURA 7: particiones creadas.
pause
dism /Apply-Image /ImageFile:"!IMAGE!" /Index:!INDEX! /ApplyDir:W:\ /CheckIntegrity /Verify /LogPath:"!LOGDIR!\dism.log"
if errorlevel 1 goto error
if not exist W:\Windows\System32\Config\SYSTEM goto error
>> "!LOGDIR!\resumen.txt" echo Imagen aplicada correctamente.
echo CAPTURA 8: DISM finalizado.
pause
W:\Windows\System32\bcdboot.exe W:\Windows /s S: /f UEFI /l es-es /bootex > "!LOGDIR!\arranque.txt" 2>&1
if errorlevel 1 goto error
type "!LOGDIR!\arranque.txt"
if not exist S:\EFI\Microsoft\Boot\BCD goto error
if not exist S:\EFI\Boot\bootx64.efi goto error
>> "!LOGDIR!\resumen.txt" echo Archivos UEFI y BCD creados.
echo CAPTURA 9: BCDBoot correcto.
pause
if not exist W:\Windows\System32\Recovery\Winre.wim goto error
md R:\Recovery\WindowsRE
xcopy /h /r /y W:\Windows\System32\Recovery\Winre.wim R:\Recovery\WindowsRE\ > "!LOGDIR!\copia-winre.txt" 2>&1
if errorlevel 1 goto error
W:\Windows\System32\reagentc.exe /Setreimage /Path R:\Recovery\WindowsRE /Target W:\Windows > "!LOGDIR!\winre.txt" 2>&1
if errorlevel 1 goto error
type "!LOGDIR!\winre.txt"
>> "!LOGDIR!\resumen.txt" echo Ubicacion de WinRE registrada, verificar estado despues de OOBE.
> "!LOGDIR!\ocultar-recovery.txt" echo select volume R
>> "!LOGDIR!\ocultar-recovery.txt" echo remove letter=R
>> "!LOGDIR!\ocultar-recovery.txt" echo exit
diskpart /s "!LOGDIR!\ocultar-recovery.txt" > "!LOGDIR!\ocultar-recovery.log" 2>&1
if errorlevel 1 goto error
>> "!LOGDIR!\resumen.txt" echo Finalizado. Pendientes: primer arranque, OOBE y verificacion final.
xcopy /e /h /i /y "!LOGDIR!" W:\ASIX-Logs >nul
if errorlevel 1 goto error
echo ===== CAPTURA 10: RESULTADO =====
type "!LOGDIR!\resumen.txt"
echo Logs: W:\ASIX-Logs, normalmente C:\ASIX-Logs tras arrancar Windows.
echo Captura 11: consultar list volume en DiskPart y salir con exit.
echo Apagar, retirar ambas ISO y arrancar desde el disco.
exit /b 0
:error
echo ERROR: detenerse. No reiniciar ni volver a ejecutar.
echo Revisar pantalla y logs en !LOGDIR!. Puede haber un despliegue parcial.
if exist "!LOGDIR!\resumen.txt" >> "!LOGDIR!\resumen.txt" echo ERROR: proceso detenido.
if exist W:\Windows xcopy /e /h /i /y "!LOGDIR!" W:\ASIX-Logs >nul 2>&1
exit /b 1

APLICACIÓN A OTROS ESCENARIOS

Otras versiones e imágenes personalizadas

En esta práctica se ha desplegado Windows 11 Pro. El mismo enfoque puede adaptarse a otras versiones, por ejemplo Windows 10, con una imagen, herramientas, controladores y configuración compatibles. El script incluido está limitado expresamente al laboratorio y a la edición Professional x64: no se utiliza sin adaptar sus comprobaciones a otro destino.

También puede prepararse una imagen personalizada con Windows, Word y una terminal, además de los ajustes y aplicaciones necesarios para un aula, una oficina o un puesto específico.

  1. Preparar un equipo o máquina virtual de referencia con la versión de Windows elegida.
  2. Instalar las aplicaciones necesarias y configurar el entorno. Revisar el procedimiento de despliegue y activación de cada aplicación.
  3. Generalizar la instalación con Sysprep y apagarla siguiendo el procedimiento correspondiente.
  4. Arrancar WinPE y capturar la partición de Windows en una imagen WIM con DISM.
  5. Adaptar y probar el script para aplicar esa imagen en los equipos de destino y completar su configuración.

Así puede repetirse una configuración preparada sin instalar manualmente cada aplicación en todos los equipos. Este escenario se explica como ampliación: en la práctica realizada se ha utilizado la imagen oficial, no se ha capturado una imagen con Word.

Aplicaciones y licencias: la ISO oficial de Windows utilizada no incluye Word. Windows y las aplicaciones añadidas necesitan sus licencias y activación correspondientes. Una imagen personalizada no transfiere automáticamente la activación ni convierte las licencias en reutilizables para cualquier equipo.
