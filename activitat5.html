03 // CLASIFICACIÓN

Tabla de elementos vulnerables

TIPO DE ACTIVO ¿QUÉ INCLUYE? EJEMPLO CONCRETO POSIBLE RIESGO
🖥 HARDWARE Todos los componentes físicos que forman parte del sistema informático. Servidor de una empresa Avería, robo, incendio o daño físico.
💻 SOFTWARE Sistemas operativos, aplicaciones, servicios y programas utilizados por la organización. Ubuntu Server Malware, vulnerabilidades, errores de configuración o software desactualizado.
🗄 DATOS Información almacenada o procesada por los sistemas de la organización. Base de datos de clientes Pérdida, modificación, destrucción, filtración o acceso no autorizado.
🔋 ELEMENTOS FUNGIBLES Materiales que se consumen con el uso y deben ser sustituidos periódicamente. Tóner de una impresora Agotamiento, pérdida o falta de disponibilidad.
👥 PERSONAS Usuarios, administradores, técnicos y demás personal relacionado con los sistemas de información. Administrador de sistemas Error humano, ingeniería social, pérdida de credenciales o acciones intencionadas.
04 // CRITICAL ASSET

¿Por qué los datos son tan importantes?

🗄️
DATA

El activo más crítico

Los datos suelen considerarse uno de los activos más críticos de una organización porque contienen la información necesaria para su funcionamiento.

Un ordenador averiado puede sustituirse y un programa puede volver a instalarse. Sin embargo, determinados datos pueden ser únicos e irreemplazables si no existe una copia de seguridad.

Una organización puede almacenar información sobre clientes, proveedores, trabajadores, facturación, proyectos, productos o documentos internos.

La pérdida, modificación o divulgación no autorizada de esa información puede provocar interrupciones del servicio, pérdidas económicas y problemas para la organización.

05 // PROTECCIÓN DE LA INFORMACIÓN

Los datos y la tríada CID

C

🔒 Confidencialidad

La información únicamente debe ser accesible por las personas autorizadas.

I

✓ Integridad

Los datos deben mantenerse correctos y no ser modificados de forma no autorizada.

D

⚡ Disponibilidad

La información debe estar accesible cuando los usuarios autorizados la necesiten.

06 // MEMORY BLOCK

EXAM MODE

⚠ CONCEPTOS IMPORTANTES
  • Un activo es un elemento que tiene valor para una organización y que debe protegerse.
  • Los elementos vulnerables del ejercicio son: hardware, software, datos, elementos fungibles y personas.
  • Hardware = componentes físicos.
  • Software = programas, aplicaciones y sistemas operativos.
  • Datos = información almacenada y procesada.
  • Fungibles = elementos que se consumen con el uso.
  • Las personas también forman parte de los elementos que deben protegerse.
  • Los datos pueden ser especialmente críticos porque, a diferencia del hardware o software, determinada información puede ser irreemplazable.
  • La información debe protegerse atendiendo a confidencialidad, integridad y disponibilidad.
07 // RESPUESTA DIRECTA

Respuesta de la actividad

¿Por qué los datos suelen considerarse el activo más crítico?

Los datos suelen considerarse uno de los activos más críticos de una organización porque contienen información esencial para su funcionamiento. Mientras que un equipo físico puede sustituirse y un programa puede volver a instalarse, determinados datos pueden ser únicos y difíciles o imposibles de recuperar si se pierden y no existe una copia de seguridad. Además, su pérdida, modificación o acceso no autorizado puede afectar al funcionamiento de la organización y comprometer la confidencialidad, integridad o disponibilidad de la información.
